# 주석 작성

## 언제 발동하나

사용자가 코드에 주석을 달아달라고 요청하면 발동한다. 규칙은 `docs/coding-convention.md` 12장(주석)이 원본이다 — 여기서는 그 규칙을 실제로 적용하는 절차만 다룬다. 두 문서가 어긋나면 `docs/coding-convention.md`가 우선한다.

## 규칙 요약 (원본: docs/coding-convention.md §12)

1. **꼭 필요한 곳에만.** 무엇을 위해 만든 것인지만 적는다 — 코드가 "무엇을 하는지"를 그대로 옮기지 않는다.
2. **코드를 읽어서 알 수 있으면 주석을 달지 않는다.** 변수·함수 이름이 이미 설명하고 있으면 주석은 잉여다.
3. **최대한 짧게.** 한 줄을 넘기지 않는 것을 기본으로 한다. 설명이 길어지면 주석을 늘리지 말고 이름을 고치거나 메서드를 쪼갠다.
4. **문서 위치를 적지 않는다.** 기획서 절 번호, 코딩 컨벤션 장 번호, 다른 파일 경로를 주석에 넣지 않는다. 근거가 필요하면 번호 대신 이유 자체를 적는다.
5. **특수 기호를 쓰지 않는다.** 별표, 이모지, 화살표, 장식 문자를 넣지 않는다. 가운뎃점(`·`)처럼 한국어 문장에서 평범하게 쓰는 것만 허용한다.
6. **마침표(`.`)로 끝내지 않는다.** 짧은 구절로 쓴다.
7. **public API는 XML 문서 주석(`<summary>`), 그 외(내부 로직 · private 멤버)는 일반 주석(`//`).** 대상이 public이라고 무조건 summary를 붙이는 게 아니라, 외부에 노출되는 계약을 설명할 때 summary를 쓴다. summary에도 3~6번이 그대로 적용된다.
8. **남은 작업은 TODO 주석으로 적극 남긴다.** `// TODO(이름): 할 일` 형식으로 담당자를 남긴다.

## 절차

1. 주석을 달 대상 코드를 읽고, 코드 자체가 이미 말하고 있는 것과 실제로 설명이 필요한 부분(왜 이렇게 했는지, 숨은 제약, 다음에 할 일)을 구분한다.
2. 코드가 이미 명확한 곳에는 주석을 추가하지 않는다 — "주석을 달아달라"는 요청이 모든 줄에 주석을 달라는 뜻은 아니다. 필요 없는 곳은 비워두고, 왜 비웠는지 설명하지 않는다(그 설명 자체가 또 하나의 잉여 주석이 된다).
3. 대상이 public API(다른 파트/팀원이 호출하는 메서드·프로퍼티·클래스)면 `<summary>` XML 주석으로, 내부 구현이면 일반 `//` 주석으로 작성한다.
4. 근거가 기획 문서에 있더라도 **절 번호를 적지 않고 그 이유를 한 줄로 옮겨 적는다.** 문서가 개정되면 번호는 어긋나는데 주석은 따라 고쳐지지 않아, 남는 것은 틀린 안내뿐이다.
5. 문장 끝에 마침표를 붙이지 않는다.
6. 미완성이거나 후속 작업이 필요한 지점을 발견하면 `// TODO(이름): 내용` 을 남긴다 — 이름은 코드를 작성 중인 사람 기준으로 붙인다. 담당자를 모르면 사용자에게 묻는다.
7. 작성 후 다시 훑어서 아래를 스스로 점검하고 제거한다.
   - 코드를 읽으면 알 수 있는 주석이 섞였는가
   - 문서 절 번호나 파일 경로가 들어갔는가
   - 별표·이모지 같은 특수 기호가 들어갔는가
   - 한 줄로 줄일 수 있는데 여러 줄로 늘어졌는가

## 예시

아래의 좋음/나쁨 표시는 이 문서의 표기일 뿐이다. 실제 주석에는 쓰지 않는다.

좋음

```csharp
/// <summary> 피해를 입힌다, 체력이 0이 되면 사망 처리 </summary>
public void TakeDamage(float damage) { }

private void ApplyKnockback()
{
    _rb.isKinematic = true; // 넉백 중 물리 끄기
}

// 스폰 시점 값으로 확정, 교전 중 최대 HP가 변하면 체력바가 어긋난다
public float HealthMultiplier;

// TODO(민성): 서버 재접속 시 스냅샷 복구 처리
```

나쁨

```csharp
_health -= damage; // 체력 감소                     코드가 말하는 것을 반복
_rb.isKinematic = true; // 넉백 중 물리 끄기.       마침표로 끝남
public float HealthMultiplier; // 강화 배수 (게임 디자인 5.2)   문서 절 번호
/// <summary> ★권위 판정 레이어 </summary>          특수 기호
```
