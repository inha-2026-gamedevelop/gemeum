# 보스 패턴 설계 (초안)

> 상태: **작업 중 — 확정 아님.** 1페이즈는 7~10개로 추릴 예정, 2페이즈는 패턴 수·세부 전부 미정.
> 작성일: 2026-08-31
> 작성: 몬스터·보스 파트 (@oname36-creator)
> 근거: [게임 디자인 9장](02-game-design.md#9-보스) — 해당 장은 이 초안이 정리되는 대로 반영 예정

이 문서는 보스 패턴을 구체화하는 과정의 기록이다. `docs/02-game-design.md` 9장이 "페이즈 수·패턴은 추후 결정"으로 비워둔 부분을 채우는 작업.

---

## 1. 설계 조건

패턴을 추리기 전에 먼저 확정한 제약. **잠정 목록 — 논의하면서 더 추가될 수 있다.**

1. **보스 패턴 중간에 어그로 스위칭이 자주 일어나야 한다.** 멀티플레이 특성상 한 사람에게 고정되면 나머지 둘이 지루해진다 — 자주 바뀌는 걸 의도적으로 설계에 넣는다. 개별 패턴(1페이즈 3번 등)에만 맡기지 않고, **어그로 전환만을 목적으로 하는 주기 발동 패턴**을 페이즈마다 하나씩 넣는 방향으로 검토 중 — 세부는 미정.
2. **특정 직업군이 강제되지 않는다.** 패턴 하나가 특정 직업(차사/신궁/무녀)만 활약하게 쏠리지 않도록 분산한다.
3. **지형을 활용한다.** 주변 돌무더기 같은 지형지물을 패턴에 엮는 방향으로 검토 중 — 2페이즈에서 파괴되는 것까지 고려. **맵 파트와 협의가 필요한 영역이라 지금은 2페이즈 8번 하나로 제한.** 추가는 맵 파트 협의 이후.
4. **총 패턴 수는 약 18개** 목표.
5. **엇박 타이밍(페인트·딜레이 변형)을 넣는다.** 레퍼런스가 다크소울류(엘든 링)라 패턴 가짓수보다 "같은 모션에서 타이밍이 갈리는 것"이 정체성에 더 가깝다. 패턴을 외워도 리듬만 믿고 구르면 맞아야 한다. 2페이즈에서 갑자기 등장하면 "안 배운 걸 시험당하는" 불공정함이 되므로 **1페이즈부터 적용**해 반사를 체화시키고 2페이즈에서 시험한다. 새 패턴을 늘리기보다 기존 패턴에 변형을 얹는 쪽을 우선한다.

## 2. 1페이즈 — 여우 형태 (10개 후보, 7~10개로 추릴 예정)

| # | 이름 | 내용 | 비고 |
|---|---|---|---|
| 1 | 여우불 봉 3연격 | 패링 가능. 성공 시 약 5초 그로기 | 패링 교보재 후보. **엇박 변형 후보**: 2타에서 끊거나 3타째에 딜레이를 주는 변주 — 단, 패링을 처음 가르치는 패턴이라 너무 얄궂으면 패링 자체를 포기하게 만들 수 있어 강도 조절 필요 |
| 2 | (1번 파생기) 360도 베기 | 그냥 휘두르기, **패링 불가**. 360도 범위라 차사도 무조건 구르기로만 회피 | 1번 성공/실패와 무관하게 이어지는 파생 패턴으로 보임 |
| 3 | 여우불 입자 날리기 | 차사에게 고정 어그로 발사(추적 아님). **이 패턴 사용 시 어그로 스위칭이 같이 일어남** | 조건 1(어그로 스위칭)을 구현하는 패턴 |
| 4 | 순간이동 기습 3연계 | 순간이동 후 3연속 공격 | |
| 5 | 분신 패턴 | 분신 2개 소환. 본체가 일정 타수 피격되거나, 분신이 일정 HP만큼 깎이면 해제 | 해제 조건이 두 갈래(본체 피격 수 vs 분신 HP) — 최종 확정 필요 |
| 6 | 추적 여우불 | 일정 거리까지 다가가면 폭발 | |
| 7 | 기억 강탈 | 개인 탈출형 QTE. 연타 대신 **화면에 뜬 특정 키보드 입력을 눌러 탈출**(팀장 의견, "사이버 유격" 느낌). 오래 잡힐수록 체력이 많이 깎임 | 원문 "아재 패턴 추가" — 액귀 관련 패턴을 여기 엮을 예정으로 보임, 확정 시 재정리 필요. **이 방식(특정 키 입력형 QTE)은 보스 전체에서 이 패턴 하나로 한정** — 다른 패턴(2페이즈 10번 등)에는 확대 적용하지 않음 |
| 8 | 정수 흡수 결계 | 영역 회피형 장판 | |
| 9 | 여우불 낙인 | 개인 회피용 장판. 플레이어 각자 발밑에 생성 — 조짐이 보이면 타이밍 맞춰 구르기 | |
| 10 | 여우 구슬 충격파 | 전방 부채꼴 장판 | |

## 3. 2페이즈 — 거대 괴수 형태 (미정, 8~12개 예상)

2페이즈부터는 좁은 범위 개인 패턴 대신 **넓은 범위 장판·지속 대미지 장판** 위주로 전환.

| # | 이름 | 내용 | 비고 |
|---|---|---|---|
| 1 | 360도 휩쓸기 | 1페이즈 2번(360도 베기)의 2페이즈 강화판 — 범위·대미지 상향. 별개 신규 패턴이 아니라 동일 패턴의 페이즈업 취급 | 패턴 수 집계 시 1페이즈 2번과 묶어서 1개로 카운트 |
| 2 | 거대 꼬리치기 | 패링 가능. 5초 그로기 | 2페이즈의 패링 교보재 후보 (게임 디자인 9.2절 "페이즈마다 패링 가능한 패턴 최소 1개" 요건 충족용으로 보임) |
| 3 | 여우불 탄막 폭격 | 수십 개 여우불 입자 공격. **추적 기능 없음** | |
| 4 | 마수 돌진 | 3인 중 랜덤 대상에게 돌진 | 직업 우선순위 없이 완전 랜덤으로 확정 — 조건 2(직업 비강제) 충돌 해소 |
| 5 | 원형 결계 안개 | 지형 제한 장판, 활동 범위를 좁힘 | |
| 6 | 여우 구슬 연쇄 충격파 | 3단 부채꼴 장판 | |
| 7 | 백귀야행 | 3인 전원에게 고대미지 단순 빔 발사. 빔 속도는 플레이어 이동속도보다 살짝 빠르게 설정 — 제자리 회피(구르기 타이밍)를 유도, 도망으로는 피하기 어렵게 | "전멸기급"이라는 표현과 달리 즉사 강제 DPS 체크가 아니라, 회피 타이밍만 맞으면 생존 가능한 단순 고대미지 패턴으로 확정. 소울류 문법(조건 5)에 맞춤 |
| 8 | 돌무더기 붕괴 돌진 | 지정된 돌무더기로 돌진, 충돌 시 파괴 + 파편 장판. 파괴된 자리는 이후 엄폐물로 못 씀 | (신규 후보) 조건 3(지형 활용) 보강용 — 페이즈 진행에 따라 아레나가 좁아지는 압박 곡선 |
| 9 | 표식 순환 처형 | 3인 전원에게 표식, 순서는 매번 랜덤/체력 역순 등으로 변경. 순서대로 일정 간격 두고 순차 폭발 | (신규 후보) 조건 1(어그로 스위칭)이 2페이즈에 없던 것을 보강. 조건 2(직업 비강제) 자연 충족 |
| 10 | 대여우 응시 (단일 대상 처형기) | 큰 예고 모션 후 한 명 지목, 그랩/돌진. 회피 성공 시 무피해, 실패 시 즉사급 대미지+그로기 | (신규 후보) 상태이상 전파형 기믹 대신 "확실히 예고되지만 순간 판단 필요한 회피"로 단순화 — 소울류 문법에 더 부합. 페이즈1 7번(기억 강탈)과의 연결은 유지하되 전파형 페널티 대신 단순 즉시 페널티로 정리하는 방향 |

**또 추가 예정** — 이 표는 최종이 아니다.

## 4. 확정되지 않은 것 (다음에 정리할 것)

- 1페이즈 10개 중 7~10개로 추릴 기준
- 2페이즈 패턴 수·세부 (지금은 7개만 나열, 목표는 8~12개)
- 5번(분신) 패턴의 해제 조건 최종 확정 (본체 피격 수 vs 분신 HP 중 하나로 정리할지, 둘 다 유지할지)
- 7번(기억 강탈) 패턴과 액귀 콘텐츠의 연결 방식
- 지형지물(돌무더기 등) 배치와 2페이즈 파괴 연출의 구체 스펙
- 전체 18개 목표 대비 현재 나열 수 조정 — 2페이즈 1번을 1페이즈 2번과 묶어 1개로 카운트하면 19개, 여전히 1개 초과. 추가로 뺄 후보 결정 필요
- 각 패턴의 수치(쿨다운·예고 시간·피해량)는 이 문서에 없다 — 패턴이 확정되면 `BossPatternSO`로 옮긴다 (코드에 수치를 박지 않는다는 원칙은 보스도 동일)
- **엇박 타이밍(조건 5) 적용 범위 확정.** 1페이즈 1번(여우불 봉 3연격)부터 적용하기로 했으나, 나머지 패턴 중 어디에 더 넣을지·강도는 어느 정도로 할지 미정
- 신규 후보 10번(대여우 응시)과 1페이즈 7번(기억 강탈)의 연결 방식 — 상태이상 전파 대신 단순 즉시 페널티로 가는 방향까지만 정해짐, 구체 수치는 미정
- **어그로 전환 전용 주기 패턴(조건 1 보강안)** — 페이즈마다 하나씩 넣는 방향만 정해짐, 구체 메커니즘·발동 주기 미정
- **지형지물 활용 패턴 확장** — 맵 파트와 협의 전이라 2페이즈 8번 하나로 제한된 상태. 협의 후 추가 여부 결정
- 설계 조건 자체가 잠정 목록 — 추가 조건이 나올 수 있음
