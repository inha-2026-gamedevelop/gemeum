# 보스 패턴 설계 (초안)

> 상태: **작업 중 — 확정 아님.** 1페이즈는 7~10개로 추릴 예정, 2페이즈는 패턴 수·세부 전부 미정.
> 작성일: 2026-08-31
> 작성: 몬스터·보스 파트 (@oname36-creator)
> 근거: [게임 디자인 9장](02-game-design.md#9-보스) — 해당 장은 이 초안이 정리되는 대로 반영 예정

이 문서는 보스 패턴을 구체화하는 과정의 기록이다. `docs/02-game-design.md` 9장이 "페이즈 수·패턴은 추후 결정"으로 비워둔 부분을 채우는 작업.

---

## 1. 설계 조건

패턴을 추리기 전에 먼저 확정한 제약 4가지.

1. **보스 패턴 중간에 어그로 스위칭이 자주 일어나야 한다.** 멀티플레이 특성상 한 사람에게 고정되면 나머지 둘이 지루해진다 — 자주 바뀌는 걸 의도적으로 설계에 넣는다.
2. **특정 직업군이 강제되지 않는다.** 패턴 하나가 특정 직업(차사/신궁/무녀)만 활약하게 쏠리지 않도록 분산한다.
3. **지형을 활용한다.** 주변 돌무더기 같은 지형지물을 패턴에 엮는 방향으로 검토 중 — 2페이즈에서 파괴되는 것까지 고려.
4. **총 패턴 수는 약 18개** 목표.

## 2. 1페이즈 — 여우 형태 (10개 후보, 7~10개로 추릴 예정)

| # | 이름 | 내용 | 비고 |
|---|---|---|---|
| 1 | 여우불 봉 3연격 | 패링 가능. 성공 시 약 5초 그로기 | 패링 교보재 후보 |
| 2 | (1번 파생기) 360도 베기 | 그냥 휘두르기, **패링 불가**. 360도 범위라 차사도 무조건 구르기로만 회피 | 1번 성공/실패와 무관하게 이어지는 파생 패턴으로 보임 |
| 3 | 여우불 입자 날리기 | 차사에게 고정 어그로 발사(추적 아님). **이 패턴 사용 시 어그로 스위칭이 같이 일어남** | 조건 1(어그로 스위칭)을 구현하는 패턴 |
| 4 | 순간이동 기습 3연계 | 순간이동 후 3연속 공격 | |
| 5 | 분신 패턴 | 분신 2개 소환. 본체가 일정 타수 피격되거나, 분신이 일정 HP만큼 깎이면 해제 | 해제 조건이 두 갈래(본체 피격 수 vs 분신 HP) — 최종 확정 필요 |
| 6 | 추적 여우불 | 일정 거리까지 다가가면 폭발 | |
| 7 | 기억 강탈 | 개인 탈출형 QTE(연타 입력으로 탈출). 오래 잡힐수록 체력이 많이 깎임 | 원문 "아재 패턴 추가" — 액귀 관련 패턴을 여기 엮을 예정으로 보임, 확정 시 재정리 필요 |
| 8 | 정수 흡수 결계 | 영역 회피형 장판 | |
| 9 | 여우불 낙인 | 개인 회피용 장판. 플레이어 각자 발밑에 생성 — 조짐이 보이면 타이밍 맞춰 구르기 | |
| 10 | 여우 구슬 충격파 | 전방 부채꼴 장판 | |

## 3. 2페이즈 — 거대 괴수 형태 (미정, 8~12개 예상)

2페이즈부터는 좁은 범위 개인 패턴 대신 **넓은 범위 장판·지속 대미지 장판** 위주로 전환.

| # | 이름 | 내용 | 비고 |
|---|---|---|---|
| 1 | 360도 휩쓸기 | | |
| 2 | 거대 꼬리치기 | 패링 가능. 5초 그로기 | 2페이즈의 패링 교보재 후보 (게임 디자인 9.2절 "페이즈마다 패링 가능한 패턴 최소 1개" 요건 충족용으로 보임) |
| 3 | 여우불 탄막 폭격 | 수십 개 여우불 입자 공격. **추적 기능 없음** | |
| 4 | 마수 돌진 | 궁수 또는 힐러에게 우선 돌진 | 조건 2(직업 강제 안 함)와의 균형 — 매번 같은 직업만 노리면 안 됨, 확정 시 확인 필요 |
| 5 | 원형 결계 안개 | 지형 제한 장판, 활동 범위를 좁힘 | |
| 6 | 여우 구슬 연쇄 충격파 | 3단 부채꼴 장판 | |
| 7 | 백귀야행 | **전멸기급 광역 패턴.** 3인 전원에게 극딜 레이저 발사 | 막타/피니셔성 패턴으로 보임 |

**또 추가 예정** — 이 표는 최종이 아니다.

## 4. 확정되지 않은 것 (다음에 정리할 것)

- 1페이즈 10개 중 7~10개로 추릴 기준
- 2페이즈 패턴 수·세부 (지금은 7개만 나열, 목표는 8~12개)
- 5번(분신) 패턴의 해제 조건 최종 확정 (본체 피격 수 vs 분신 HP 중 하나로 정리할지, 둘 다 유지할지)
- 7번(기억 강탈) 패턴과 액귀 콘텐츠의 연결 방식
- 지형지물(돌무더기 등) 배치와 2페이즈 파괴 연출의 구체 스펙
- 전체 18개 목표 대비 현재 나열된 17개(1페이즈 10 + 2페이즈 7)와의 차이 조정
- 각 패턴의 수치(쿨다운·예고 시간·피해량)는 이 문서에 없다 — 패턴이 확정되면 `BossPatternSO`로 옮긴다 (코드에 수치를 박지 않는다는 원칙은 보스도 동일)
