### 1.1 한 줄 소개

그믐밤이 걷히기 전, 세 차사가 원귀의 근원을 베고 저승으로 돌아와야 한다.

### 1.2 세계관

명부에 오르지 못한 혼이 원귀가 되어 이승과 저승 사이의 길을 막았다.
저승은 달이 사라진 그믐밤에 세 명의 차사를 내려보낸다.
날이 밝기 전 근원을 베지 못하면, 차사 역시 그 밤에 갇힌다.

최종 보스는 조선을 멸하러 온 외세 침입군 병사의 원혼이다. 명부에 오르지 못한 채 저승길을 막고 있다.

### 1.3 K-Culture 요건 충족

| 요소 | 적용 |
|---|---|
| 스토리 | 저승사자 · 차사 신화, 명부 설정 |
| 캐릭터 | 차사(검) / 신궁(활) / 무녀(방울) |
| 아이템 | 노잣돈, 부적, 신물 등 전통 명명 |
| 배경 | 한옥, 장승, 솟대가 선 저승 어귀 |
| 시장성 | 케데헌, 도깨비, 호텔 델루나 등 검증된 한국 IP 계보 |

## 2. 코어 루프

```
런 시작
  └ 무기 강제 배분 (검 / 활 / 방울 각 1)
      └ [개활 파밍] 잡귀 처치 → 장비 · 노잣돈 · 경험치
          └ [1차 결계 축소]
              └ [2차 결계 축소] → 객주 NPC 상호작용 (구매)
                  └ [3차 결계 축소] → 보스맵 진입
                      └ 최종 보스전
                          ├ 승리 → 점수 정산 → 리더보드 등록
                          └ 전원 사망 → 런 종료
```

### 2.1 진행 타임라인 (총 25분 목표)

| 구간 | 실시간 | 게임 내 시각 | 활동 범위 | 결계 피해 | 객주 |
|---|---|---|---|---|---|
| 개활 파밍 | 0:00 – 7:00 | 08:00 – 12:40 | 100% | 없음 | — |
| 1차 축소 | 7:00 – 12:00 | 12:40 – 16:00 | 50% | 초당 1 | — |
| 2차 축소 | 12:00 – 15:00 | 16:00 – 18:00 | 30% | 초당 2.5 + 쇠약 | 있음 |
| 3차 축소 | 15:00 – 15:30 | 18:00 – 18:20 | 보스맵 이동 | 초당 5 + 회복 봉쇄 | — |
| 보스전 | 15:30 – 최대 25:00 | 18:20 – 자정 무렵(연출 기준) | 보스맵 | 없음 (보스맵 진입 후 결계 종료) | — |

- 아침 8시에 시작하여 해질 무렵 보스전에 진입하고, 그믐 자정 무렵에 결착한다.
- 실시간 1분 30초가 게임 내 1시간에 해당한다.
- 축소 연출은 30초에 걸쳐 진행하고, 10초 전 경고 UI를 띄운다.
- 쇠약: 회복 효율 30% 감소.
- 회복 봉쇄: 결계 밖에서 모든 회복 수단 무효.
- 3차 축소가 끝나는 실시간 15:30에 보스를 활성화한다. 보스가 처치되지 않은 채 실시간 25:00에 도달하면 실패로 종료한다.
- 게임 내 자정은 조명과 연출의 기준이다. 실제 런 종료 시각은 보스 처치 또는 실시간 25:00으로 판정한다.

#### 맵 배치 제약 — 보스맵 입구는 3차 결계 안에 있어야 한다

3차 축소 구간은 **30초**이고 결계 밖 피해는 초당 5, 회복 봉쇄가 함께 걸린다.
이 구간 내내 결계 밖에 있으면 누적 150 피해로, 10레벨 최대 HP 180의 대부분이 사라진다. 회복 수단도 막혀 있다.

따라서 **보스맵 입구는 3차 결계의 최종 반경 안에 배치한다.** 이 제약을 어기면 보스전 진입 자체가 파티 전멸 구간이 된다.
맵 레이아웃 확정 시 결계 중심(`BarrierCenter`)에서 보스맵 입구까지의 거리를 3차 최종 반경보다 작게 잡을 것 — 담당은 테크니컬 아트, 검증은 3인 통합 테스트에서 한다.

### 2.2 핵심 재미

시간이 지날수록 좋은 장비가 나오지만, 동시에 결계가 조여 온다.
한 번 더 주울 것인가, 지금 물러설 것인가 — 이 저울질이 게임의 축이다.

### 2.3 세션과 런 시작 규칙

- 실서비스 런은 **정확히 3명**을 기준으로 한다. 로비는 3명이 준비 완료할 때까지 시작하지 않는다.
- 서버가 런 시작 순간 검 · 활 · 방울을 중복 없이 한 자루씩 무작위 배분한다. 접속 순서나 플레이어 이름으로 직업을 고정하지 않는다.
- 런이 시작된 뒤에는 신규 접속과 재접속을 허용하지 않는다. 프로토타입에서는 호스트 또는 클라이언트가 이탈하면 해당 런을 중단하고 리더보드에 등록하지 않는다.
- 개발 씬의 단독 테스트는 허용하지만, 완주 판정과 네트워크 검증은 3인 접속에서만 유효하다.

## 4. 팀 구성과 역할

| 파트 | 담당 | 핵심 기술 (1인 1개 요건) |
|---|---|---|
| 네트워크 · 전투 (팀장) | 서버, 플레이어 조작, 패링, 화살 보정 | 네트워크 환경에서의 패링 판정 동기화 |
| AI · 보스 설계 | 보스와 잡귀, 결계 단계별 난이도 | 보스 패턴 상태 머신 |
| 게임플레이 시스템 | 장비 드랍, 특성, 노잣돈 경제, 점수 | 가중치 기반 절차적 아이템 생성 |
| 테크니컬 아트 | 셰이더와 연출, **맵 구성** | URP 기반 렌더링 및 아트 파이프라인 |

UI는 각자 자기 시스템의 UI를 담당한다. UI 전담자를 두지 않는다 — 다른 시스템 완성을 기다리는 병목이 생기기 때문이다.

## 6. 스코프 통제 원칙

완성을 최우선한다. 아래는 프로젝트 시작 시점에 고정하며, 변경하려면 팀 전체 합의를 거친다.

| 항목 | 확정 |
|---|---|
| 보스 | **1마리로 확정.** 여유가 생기면 그때 1마리 추가 검토 |
| 맵 | **고정 맵 + 랜덤 스폰.** 절차적 지형 생성 없음 |
| 제작 · 합성 | **없음.** 주우면 바로 사용 |
| 인벤토리 | 슬롯형 3~4칸, 확장 없음 |
| 특성 트리 | 직업당 2줄 × 5노드 |

주 단위 스프린트로 각자 산출물을 확인한다. 4주차에 없는 기능을 발견하면 손 쓸 방법이 없다.

## 7. 에셋 정책

### 7.1 게임 리소스

| 구분 | 방침 | 상태 |
|---|---|---|
| 지형 도구 | Gaia for Unity 6 | **구매 완료** |
| 한국 건축물 | 동양풍 에셋 구매 후 배치, 한국 상징물 일부 직접 모델링 | 미확보 |
| 캐릭터 | 구매 또는 무료 라이선스 | 미확보 |
| VFX | 구매 또는 무료 라이선스 | 미확보 |
| 사운드 | 국악 요소 포함 라이브러리 | 미확보 |

라이선스는 상업 이용 가능 범위로 관리한다. 출품전 제출을 대비해 근거 문서를 보관할 것.

### 7.2 개발 보조 도구

| 도구 | 용도 |
|---|---|
| Editor Console Pro 3 | 로그 필터링과 스택 추적. 네트워크 디버깅 시 활용 |
| Hierarchy Designer | 하이어라키 정리. 씬 분리 작업 시 구조 파악 |
| Maintainer 2 | 에셋 참조 검사, 미사용 리소스 탐지, 빌드 전 정리 |

Maintainer 2는 구매 에셋을 다수 도입하는 프로젝트 특성상 미사용 리소스가 쌓이기 쉬우므로, 마감 전 빌드 용량 정리에 활용한다.

### 7.3 맵 규모 제한

맵 크기는 500m~800m 규모로 제한한다. Gaia는 광활한 지형을 쉽게 만들 수 있어 과욕 위험이 있으나, 25분 런에 3인 협동, 결계 축소 구조에서는 큰 맵이 오히려 공허해진다.
