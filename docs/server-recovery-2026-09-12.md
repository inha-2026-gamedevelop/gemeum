# 런 복구·종료 검증 절차

이 경로는 기존 문서 링크를 유지한다. 날짜별 개인 실행 로그 대신 팀이 재현할 계약을 기록한다.

런 상태는 스냅샷 운반자와 `RunManager` 복구 경로를 통해 복원한다. 종료된 런의 늦은 콜백이 새 런을 시작하거나 정산을 중복 확정하면 안 된다. 빈 운반자·중복 종료·씬 전환 중 이탈·전원 이탈을 각각 확인한다.

1. 현재 커밋과 빌드 ID, 씬, 전송 경로를 기록한다.
2. 정상 3인 런에서 단계 전환·복구·결과 수신을 확인한다.
3. 운반자 누락과 중복 콜백을 개발 도구로 재현해 거부·정리를 확인한다.
4. 종료 후 늦은 콜백과 재시작 시 이전 런 상태가 유입되지 않는지 확인한다.
5. 호스트 종료를 별도로 시험한다. 자동 호스트 이전은 현재 제공되지 않는다.
