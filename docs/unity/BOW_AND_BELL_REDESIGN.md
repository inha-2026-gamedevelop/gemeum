# 활·방울 — 약점과 잔향의 현재 계약

2026-09-22 코드 대조. 활·방울 기본 능력, R, 13노드 특성이 구현되어 있다. 수치 밸런스·타격감·서로 다른 PC 3인 검증은 별도다. 과거 정밀 사격 설치·6초 쐐기·1B 파열 설계는 현재 계약이 아니다.

## 활: 접근해서 새기고 조준해서 파열

R 파고들기가 근접 이동·피해와 쐐기를 설치한다. 소유자당 1개, 기본 8초이며 기존 자기 표식은 새 설치에 교체된다. 일반 사격 2회 또는 정밀 사격 1회가 중심 궤적으로 쐐기를 통과하면 추가 2B 기본 피해로 파열한다. 해당 소유자의 공격만 자기 표식을 소비한다.

정밀 사격은 쐐기를 새로 설치하지 않는다. 정밀 사격은 발사 스냅·유도 없이 직접 조준하며, 자기 쐐기 활성 중 일반 사격도 같은 수동 조준 예외를 적용한다. 기본 일반 사격의 보조와 보스 정밀 카운터는 [화살 조준](ARROW_AIM_ASSIST_DESIGN.md)을 따른다.

표식 위치는 실제 맞힌 부위를 따르고 벽·대상 세대·소멸·무기 교체를 검사한다. 파열 추가 피해가 새 표식이나 재귀 파열을 만들면 안 된다. 상세 수치와 취소 조건은 [검·활 구현](SWORD_BOW_REWORK_IMPLEMENTATION.md), [R 계약](WEAPON_ACTIVE_SKILLS.md)을 따른다.

## 방울: 남긴 잔향을 회수하고 공격할 자리를 만든다

기본 타격은 잔향을 남기며 동료 직접 공격은 서버 검증을 거쳐 충전한다. Q 회수는 `PlayerAttack.abilities.cs`가 대상·충전·자원·시야·수명을 확정한다. 직접 피해로 발생한 잔향과 보스 공동 그로기용 `MarkRegistry` 낙인은 다른 계약이다. Q가 기존 낙인을 소비·갱신하지 않는다.

우클릭 치유는 유지한다. R은 지면 조준 후 좌클릭 설치하는 공격 지원 진이다. 기본 6초·반경 3m·공격력 1.10배·이탈 1.5초이며 설치 타격 한 번 후 두 번째 공격파는 없다. [방울 구현](BELL_RESONANCE_IMPLEMENTATION.md)을 기준으로 체류·잔여 버프·자기 진 특성의 조건을 확인한다.

## 공통 구현 경계

피해 직전/직후 유효 HP 감소, 공격자와 행동 ID, 런·씬 세대로 적중·충전을 검증한다. 표시용 표식이 보인다고 서버 효과를 확정하지 않는다. 방울 회수와 활 파열은 파생 피해로 처리해 원인 행동을 재발생시키지 않는다.

특성은 무기당 13개다. 실제 NodeId·효과·선행 관계와 UI 호출은 [특성 UI 인계](TALENT_UI_HANDOVER.md)에서 확인한다. 봇의 새 R·쐐기·지원진 판단은 사람 구현 존재만으로 완료 처리하지 않고 별도 플레이 검증한다.

## 표현과 검증

활은 손의 당김·발사·표면 파열을, 방울은 타격·충전·회수·지면 설치를 구분한다. 발사음은 실제 발사 시각, 타격 표현은 서버 수락 cue를 따른다. 원거리 명중 때문에 사수 모션을 멈추지 않는다. 표식과 쿨다운은 WeaponAbilityHUD로 표시한다.

정상 사용 외에 피격 취소·사망·무기 교체·씬 전환·일시정지·중복 요청·가까운 벽·부위 파괴를 확인한다. 같은 PC M2와 외부 3인 M3, 시각 캡처와 사용자 손맛 평가는 서로 다른 증거다.

## 12. 임포트 모션·전용 이펙트 적용 (2026-09-21)

원본은 `Assets/99.ThirdParty/ExplosiveLLC/RPG Character Mecanim Animation Pack/Animations`다. 구매 원본은 변경하지 않고 프로젝트 소유 `.anim`으로 추출·재타이밍했다. 재생성 메뉴는 `Geumeum/Art/Bake Bow and Bell Motions`, 제작 코드는 `WeaponMotionBaker.cs`다.

| 행동 | 사용 원본 | 연결 방식 |
|---|---|---|
| 활 일반 공격 | `2Hand-Bow-Attack1` | 원본 Shoot 프레임을 0.25초에 맞추고 전체 0.60초로 재타이밍 |
| 활 정밀 당김·유지·발사 | 같은 Attack1 | 발사 전 구간을 0.60초로 당김, 마지막 당김 자세 유지, 발사 후 구간은 0.35초 |
| 활 대기·걷기·달리기 | Bow Idle/Walk/Run-Foward | 기존 활 컨트롤러의 기본 이동 블렌드에 연결 |

| 방울 치유 | `Unarmed-Cast-R-Buff1_start/end` | 시전 0.40초, 회복 포함 0.80초 |

- 공격·시전 클립의 루트와 하체 기준을 고정해 원본의 전진·깊은 웅크림이 이동 판정과 충돌하지 않도록 했다. `applyRootMotion=false` 유지. 실제 판정·이동·비용은 서버 코드가 담당한다.
- 원본 `Shoot` AnimationEvent는 작업 클립에서 제거한다. 화살 생성과 피격은 애니메이션 이벤트로 발생시키지 않는다.
- 기존 오른손 활 부착에 맞춰 활 모션을 미러링했다. Player 프리팹의 세 캐릭터별 활 부착 각도도 새 당김 자세에 맞춰 보정했다.
- 모든 캐릭터 컨트롤러에 BowAttack/Draw/Hold/Release, BellStrike/EchoRecall/BellHeal 상태를 연결했다. 캐릭터와 무기의 조합이 바뀌어도 해당 상태를 쓸 수 있다.
- 정밀 당김은 기존 서버 HoldGeneration/시작 시간/State를 읽는다. 실제 발사는 기존 BowReleased 메시지에서 정밀 여부를 전달한다. 짧은 이펙트의 지연 생략과 발사 모션 적용을 분리한다.
- 일시정지 중 전환이 멈추더라도 해당 행동의 서버 시간표로 정지 자세를 평가한다. 피격 모션이 공격·시전보다 우선한다.

### 이펙트

- 활: 조준할수록 수축·완성되는 금색 초점, 발사점의 짧은 방사광, 명중·쐐기 파열의 별도 파편광.
- 방울: 손 높이에서 진행하는 전방 3겹 음파. 잔향 충전은 적 표식에서 짧게 번쩍이며, Q는 각 적 표식에서 방울 손으로 돌아오는 3가닥 곡선으로 표현한다.
- 회수 곡선은 시전 시간 0.18초에 맞춰 도착한다. 피격으로 취소되면 남아 있는 회수 곡선을 즉시 끊고 성공 파열은 실제 서버 피해 이벤트에만 표시한다.
- `Geumeum/WeaponAbilityGlow` 셰이더로 부드러운 가장자리·밝은 중심선을 표현한다. 깊이 검사를 유지해 벽 너머로 그리지 않는다.
- 선 렌더러는 플레이어마다 미리 확보해 재사용한다. 색·선폭·파편 길이·초점 반경·곡선 휘어짐은 PresentationConfigSO에서 조정한다. 이펙트는 게임 시간 기준으로 일시정지한다.
