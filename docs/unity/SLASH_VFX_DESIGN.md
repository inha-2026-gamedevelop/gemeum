# 검기 VFX — 현재 구현

2026-09-22 VFX 개편 반영. 무기 궤적 기반 구현을 유지하고 색·잔상·셰이더만 조정했다. 폐기된 고정 초승달·AnimationCatalogSO 제안은 적용하지 않는다. 현재 조정 방향은 [전투 VFX](COMBAT_VFX_DIRECTION.md)를 따른다.

## 1. 구현 기록 (2026-09-18)

설계와 달라진 점과 이유만 적는다. 판정 권위 원칙(2장)은 그대로 지켰다. 검기는 여전히 판정에 관여하지 않는다.

### 11.1 초승달에서 검날 궤적으로

처음에는 설계대로 판정 각도로 만든 초승달을 플레이어 정면에 띄웠다. **공격 방향과 검이 실제로 지나간 경로를 따르지 않아** 같은 날 궤적 방식으로 바꿨다.

- 플레이어 루트가 아니라 모델이 조준 방향으로 돌기 때문에 루트 정면에 붙인 이펙트가 공격 방향과 어긋났다
- 공격 클립(`S_Attack_1~3`, 속도 2배)의 칼끝은 단마다 사선 · 크게 돌려 베기 · 올려 베기로 전혀 다른 경로를 그린다. 고정 도형으로는 맞출 수 없다

그래서 5장의 "판정 거리와 각도로 크기를 유도한다"는 규칙은 폐기했다. 크기와 방향은 애니메이션이 정하고, 판정과의 일치는 애니메이션과 판정 범위를 맞추는 문제로 넘어간다.

### 11.2 현재 구조

| 항목 | 구현 |
|---|---|
| 전파 | 새 RPC 없이 기존 `PlayerActionCue`. 설계 이후 cue 계약이 먼저 생겨 전파 경로를 하나로 유지했다 |
| 검 위치 | `IWeaponBladeSource`(`00.Common`)를 `PlayerWeaponVisual`이 구현한다. 부착할 때 가장 큰 메시의 긴 축에서 손에 먼 끝을 칼끝으로 한 번 찾아 두고, 매 프레임은 변환만 한다. 모델별 칼끝 좌표를 따로 적지 않는다 |
| 기록 구간 | 판정 시각 `MeleeSlashRecordBeforeImpactSeconds`(0.1) 전 ~ `MeleeSlashRecordAfterImpactSeconds`(0.2) 후. 클립 샘플링으로 정했다. 3단은 휘두르는 순간이 판정 뒤 0.13~0.18초에 있어 뒤쪽을 0.2까지 둔다 |
| 기록 | `LateUpdate`(애니메이션 뒤)에 손잡이 쪽(`MeleeSlashHiltRatio` 0.25 지점)과 칼끝을 점으로 남긴다. 검이 멈추면 점을 쌓지 않는다 |
| 곡선 | 프레임 사이를 centripetal Catmull-Rom으로 4등분한다. 빠른 휘두르기에서 프레임 간격이 크게 달라져도 곡선이 튀어나가지 않는다 |
| 잔상 | 점마다 나이를 먹여 `MeleeSlashTrailSeconds`(0.22) 뒤 사라진다. 수명 20%부터 침식하며 얇은 칼끝과 낮은 불투명도의 몸통을 남긴다 |
| 수명 | 리본은 월드 좌표라 플레이어에 붙이지 않는다. 다음 행동이나 취소 때 반납하지 않고 기록만 멈춘다(`ReleaseCue`). 연속 콤보에서도 이전 잔상이 끝까지 남고, 점이 다 사라지면 스스로 풀에 돌아간다 |
| 시간 | 기록 구간은 서버 cue 시각을 기준으로 하되 원격은 `AbilityVisualClock`으로 스냅샷 사이를 보간한다. 호스트는 원본 게임 시각, 잔상 나이는 런 일시정지를 뺀 실제 시간. 일시정지 중에는 둘 다 멈춘다 |
| 조정값 | `AnimationCatalogSO` 대신 이미 있는 `PresentationConfigSO`. `CombatConfigSO`에 섞지 않는다는 원칙(5.3)은 유지 |
| 셰이더 | Shader Graph 대신 URP HLSL `Geumeum/MeleeSlash`. 텍스처 없이 노이즈를 절차 생성한다 |
| 색 | 검의 물리 궤적은 저채도 강철색 몸통과 따뜻한 백색 칼끝으로 개편했다. 직업 식별색과 피격 판정 색을 검기 전체에 덮어쓰지 않는다 |

설계의 4단계(Animation Event 전환)는 더 이상 필요 없다. 애니메이션이 이미 검을 움직이고 검기는 그 결과를 읽기만 한다.

**여전히 미결정:** Bloom intensity(칼끝 테두리가 발광하지 않고 흰색으로만 보인다), 치명타 검기. 공격 클립이 판정 범위보다 넓거나 좁게 휘두르면 검기도 그대로 보인다. 그때는 검기가 아니라 클립이나 판정 수치를 맞춘다.

**검증:** EditMode `CombatHitFeedbackTests`(기록 구간, 나이, 곡선 통과점과 튐 방지, 칼끝 판별, 가짜 검 궤적 추종과 잔상 뒤 반납, 설정값). 에디터에서 실제 차사 모델, 검 프리팹, `S_Attack_1~3` 클립을 60fps로 진행해 렌더로 경로와 잔상 확인. `Dev_*` 씬 실제 공격(L2)과 3인 화면(L3)은 미검증.
