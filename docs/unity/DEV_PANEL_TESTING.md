# 개발 패널 테스트

개발 빌드에서 로그에 표시된 로컬 개발 패널 주소를 연다. 기본 포트는 8787이며 여러 프로세스는 다음 빈 포트를 사용한다.

- **테스트 도구**: 런 조건, 성장·장비·지급, 보스 페이즈·패턴, 표현 조정.
- **프레임 · 로그**: 프레임 측정과 로그 두 패널만 표시한다.

게임 상태 변경은 호스트 패널에서 실행한다. 성장·재화는 파티 공용이며 장비·소모품은 선택한 플레이어(봇 포함)에게만 지급한다. 실제 기획 수치는 GameDB의 SO에서 읽는다.

| 시험 항목 | 준비 / 조작 |
|---|---|
| 레벨·최대 HP·특성 포인트 | 경험치 지급, 레벨 +1, 최대 레벨 → HUD에서 특성 투자·초기화 |
| 모든 무기·등급 | 무기와 등급 선택 → 배낭 지급 → HUD 장착·양도 |
| 착용 장비 수치 | 실제 장비(#0 기본 무기 제외) 착용 → 무작위 재조정 / 등급 변환 / 범위 내 공격력 지정 |
| 장비 특수옵션 | 착용 무기의 공용·전용 옵션 선택 → 슬롯과 범위 내 수치 지정. 같은 옵션 중복 불가 |
| 물약·티켓·구매 | 개별 소모품·노잣돈 지급 → HUD 사용·구매. 소지 제한과 중첩 제한 유지 |
| 결계·객주·시간 제한 | 게임 시간 전진. 정상 타임라인을 따라 전진하며 되감지 않는다 |
| 피해·치유·신력 | 대상 피해·회복·충전. 피해 시험 시 무한 자원을 끈다 |
| 처치·드롭·공유 보상 | 필드 잡귀 처치. 드롭 확률은 정상 기획 유지 |
| 보스 진입 | 런 시작 후 Boss로 전환. 실제 런 phase와 씬을 함께 전환 |
| 보스 페이즈 | 1/2페이즈 재시작. 이전 공격 취소, HP·부위·원혼 초기화, 서버 상태 동기화 |
| 패링·정밀 사격·표식·꼬리 | 현재 페이즈 패턴 실행 / 그로기·꼬리 노출 후 인게임 전투 조작 |

티켓을 소비하는 정상 재조정과 개발용 무소비 강제 조정은 별개다. 장비 조정은 기존 장착 조건(생존·전투 이탈·런 진행·전환 및 정지 아님)을 따른다. 실패하면 패널 결과를 확인한다. 페이즈 재시작은 처치된 보스를 되살리지 않으며, 죽은 보스는 새 런에서 시험한다.

캐릭터 선택·준비·Steam 방 생성/참가/초대·런 포기·보스 트라이 편성 제출·정산 재시도 등 정상 UI가 제공하는 버튼은 개발 패널에서 제외했다. 특성 노드와 각 전투 행동은 정상 HUD·입력을 사용한다. 기획 문서에만 있고 아직 게임에 구현되지 않은 콘텐츠는 개발 패널이 대신 구현하지 않는다.

## 검증 기준

- EditMode 검사는 현재 브랜치에서 다시 실행하고 통과·실패·제외 수를 함께 기록한다.
- M2는 한 PC의 호스트 1개와 클라이언트 2개로 실행하며, 세 화면의 서버 상태와 대상별 지급 결과가 같은지 확인한다.
- 페이즈 재시작은 이전 공격 취소, HP·부위·원혼 초기화와 세 클라이언트의 snapshot 일치를 확인한다.
- 브라우저 새로고침 뒤에도 패널이 현재 상태를 다시 표시하는지 확인한다.
- Steam 3PC와 장시간 자연 플레이를 실행하지 않았다면 별도 미검증으로 남긴다.
