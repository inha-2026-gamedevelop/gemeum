# 방울 R 공명진 구현

2026-09-21. [플레이어 개편안 v4](PLAYER_COMBAT_REWORK.md)의 방울 R·방울 특성 부분을 구현했다. 검·활 전면 개편과 전체 무기 특성 트리는 별도 작업이다. 수치는 플레이 평가용이다.

## 조작과 효과

- R로 설치 조준, 좌클릭으로 확정. 우클릭·Esc·R 재입력은 취소한다. 조준 중에는 이동할 수 있으며 카메라 회전과 공격·치유·Q·락온 입력을 잠근다.
- 설치 거리 5m, 기본 반경 3m, 신력 15, 쿨다운 12초, 준비·후딜 각각 0.25초. 서버가 거리·지면·높이·시야와 플레이어 상태를 다시 검사한다.
- 준비 중 피격·회피 취소는 예약을 해제한다. 생성 시 비용·쿨다운이 확정된다. 생성 타격은 0.3배 한 번이며 잔향·신력·후속 공격파를 만들지 않는다.
- 공명진은 6초 유지되며 안에 있는 살아 있는 자신·동료에게 공격력 10%를 부여한다. 벽과 1.5m 초과 높이차를 검사한다. 이탈 후 마지막 갱신부터 1.5초 유지한다.
- 같은 종류는 중첩하지 않는다. 각 시전자·설치 원천별 만료를 따로 보관한다. 자연 만료는 잔여시간을 남기지만 시전자 사망·삼킴·무기 교체·런/씬 종료·접속 종료는 해당 잔여 효과까지 회수한다.
- 기본 공격은 실제 타격·발사, R은 생성/타격/슬라이딩 시작, Q는 회수 비용 확정 시 배율을 고정한다. 이미 발사된 투사체에 다시 곱하지 않는다.
- 장비 옵션 401은 잔여시간만 늘린다. 기본 1.5초에 장비 백분율과 특성 추가시간을 반영하며 상한은 2.5초다. 기존 치유 공격력 버프는 제거했다.

## 방울 특성

3101~3113의 새 식별자를 사용한다. 뿌리 하나와 거두는 길·지키는 길·퍼뜨리는 길 각 네 노드를 명시 선행 관계로 연결한다. 구 enum 번호는 재사용하지 않는다. 기존 검·활 트리를 유지한다.

Q 회수 연장과 진 안 유효 치유 연계는 원천별 한 번 제한을 적용한다. 공격·피격·사망·조준·활성 진·자기 잔여 효과·임시 할인권 중에는 서버가 특성 변경을 거절한다. 자세한 수치는 v4의 10절과 TalentTreeSO.asset을 기준으로 한다.

기존 프리팹의 UI를 실행 시 확장해 모든 노드와 선행 연결선을 표시한다. 이는 전체 특성 화면 개편의 최종 아트 시안은 아니다.

## 검증과 한계

- 관련 EditMode 83개 통과. UI 배율 수정 후 UI 12개 재통과.
- 같은 PC의 호스트+원격 클라이언트 2개에서 설치 조준/취소/확정, 10% 적용, 이탈·재진입·잔여시간, 일시정지, 자연 만료 뒤 시전자 사망 회수를 확인했다.
- 테스트의 조준 진입/확정은 개발용 명령을 사용했다. 실제 마우스 조작의 사용감과 세 PC의 지연 환경(M3), 모든 특성 조합의 실전 밸런스는 별도 평가가 필요하다.
- 서버·공개 런처 패키지에는 배포하지 않았다. 로컬 개발 빌드의 버전은 기존 운영 API 허용 버전과 다를 수 있다.

실제 마우스 사용감, 서로 다른 PC 3대와 지연 환경, 전체 특성 조합의 밸런스는 별도 검증 대상이다.
