# 전투 VFX 표현 방향

2026-09-22 적용. 세키로와 엘든 링의 전투 효과를 참고해 짧은 충돌 섬광, 얇은 무기 궤적, 무게감 있는 불티와 잔광을 목표로 한다. 유사도 90%를 객관적으로 측정하거나 보증한 결과는 아니다.

참고 자료는 [세키로 공식 게임플레이 소개](https://blog.activision.com/sekiro/2019-03/Sekiro-Shadows-Die-Twice-Gameplay-Overview-Trailer-is-Here), [엘든 링 공식 게임플레이 소개](https://www.bandainamcoent.com/news/elden-ring-gameplay-preview)다. 아래 수치와 형태는 그믐에서 제작한 표현이며 원작의 측정값이나 추출 에셋이 아니다.

## 적용 범위

| 표현 | 현재 변경 |
|---|---|
| 검 기본 공격 | 실제 검날 궤적 유지, 잔상 0.6초에서 0.22초, 넓은 붉은 면을 저채도 강철색과 얇은 백색 날로 교체 |
| 패링 성공 | 성공 결과 통지 이후에만 짧은 금빛 충돌 섬광, 방향성 불티, 낙하·감쇠 재생 |
| 활 | 큰 십자 섬광 축소, 발사 방향으로 좁게 퍼지는 불티, 충전 입자는 원운동 대신 손으로 수렴 |
| 방울 | 청백색의 부드러운 입자와 끊어진 광륜, 장판 내부의 비대칭 상승 입자 |
| 피격 | 빨간 피격 표시 유지, 지속 시간을 0.12초에서 0.075초로 단축 |

장판의 실제 범위, 설치 가능/불가능 표시, 남은 시간 표시는 유지한다. 공격 판정·사거리·피해량·히트스톱·네트워크 메시지·오디오 에셋은 변경하지 않는다. 보스 패턴과 전체 화면 후처리는 이번 변경 대상이 아니다.

## 구현과 조정

- 표현 수치는 `Assets/09.Data/Presentation/PresentationConfigSO.asset`과 `PresentationConfigSO`에 있다. 클래스 기본값만 바꾸면 기존 SO에는 적용되지 않으므로 둘을 함께 확인한다.
- 검기는 `MeleeSlash.shader`와 `Assets/12.Materials/Player/M_MeleeSlash.mat`이 실제로 사용한다. 저장된 머티리얼 값이 셰이더 기본값보다 우선한다.
- 능력 효과는 `PlayerCombatPresentation.radiance.cs`의 고정 메시 예산 384쿼드를 재사용한다. 매 타격마다 입자 오브젝트를 만들지 않는다.
- `WeaponAbility.mat`의 기본 곱 색을 흰색으로 고쳤다. 이전 빨간색·알파 0.35가 모든 메시 입자에 다시 곱해져 직업별 색과 밝기가 틀어지던 문제를 제거했다. 선 표현은 기존 MaterialPropertyBlock 색을 유지한다.
- 검기는 `AbilityVisualClock`으로 원격의 0.5초 간격 시각 갱신 사이를 보간한다. 서버의 판정 시각이나 사거리는 바꾸지 않는다. 호스트는 원본 시각을 유지하고 일시정지 때 기록·잔상 노화를 멈춘다.
- 성공 패링은 동일 실행 ID의 중복 통지를 무시하고 비활성화 때 정리한다. 성공 수신 뒤 남은 선딜이 끝나면 현재 검 위치에 고정하고 별도 표현 나이를 계산하며 런 일시정지 중 멈춘다. 보간된 게임 시각이 앞서 있더라도 수신 즉시 효과가 만료되지 않는다.
- 성공 패링 통지가 다음 시각 스냅샷보다 먼저 도착해 버려지는 문제도 수정했다. 같은 행동 종류·실행 ID이고 최대 0.5초 앞선 성공 통지만 허용하며, 오래된 통지와 다른 행동은 계속 거부한다. 섬광과 같은 게이트 뒤의 기존 패링 성공 효과음 누락도 함께 복구한다.
- 기존 성공 결과가 TargetRpc이므로 새 성공 패링 불꽃은 당사자 화면에만 재생된다. 충돌 좌표가 통지에 없으므로 현재 검날 위치 또는 손 위치를 쓰며 정확한 적 무기 접점은 아니다.

## 검증과 남은 확인

Unity 컴파일·셰이더 오류 검사, 표현·검 궤적·시계 회귀 테스트 34개 통과. 성공 효과는 시계가 0.5초 앞선 상황, 중복 통지, 일시정지, 수명 종료, 비활성화 정리를 추가 검증했다.

Unity 실제 셰이더와 표현 메시로 720p 시간별 렌더를 확인했다. 검기는 같은 합성 궤적에서 전후 재질·수명 비교, 능력 효과는 15/55/130/260ms 표본이다. 합성 렌더와 실제 플레이 캡처를 구분한다. 로컬 3개 프로세스의 Development 검증 빌드를 사용하며 운영 배포와는 별개다. 검증 맵은 Boot를 거치지 않아 효과 풀이 없으므로 `ability_vfx_setup`으로 준비한 뒤 최소 한 프레임 기다린다. 창을 숨기면 애니메이터 컬링으로 검날 궤적 검증이 왜곡될 수 있어 창을 표시한 상태에서 확인한다.

검증 맵의 일부 원격 적 프리팹 미등록과 정산 provider 부재는 별도 한계다. 이 환경의 효과 캡처를 외부 3PC 접속, 적 피격 전체, 정상 런 완주 또는 운영 맵 성능 검증으로 확대 해석하지 않는다. 전체 배경·후처리 조합과 GPU 성능 예산은 별도 프로파일링 대상이다.

### 로컬 실행 확인

최종 Development 빌드에서 호스트+클라이언트2의 검기 메시 생성, 실제 성공 패링 RPC 이후 당사자 섬광, 활 충전·발사, 검 반격, 방울 공격·장판을 확인했다. 일반 게임 카메라에서 장판·충전·검 공격 동시 표시와 해제 후 세 화면의 잔여 효과 정리도 통과했다. 패링 입력은 개발용 합성 공격 소스로 서버 판정 경로를 호출했으며 실제 보스전 입력 검증과 구분한다. 충전은 PlayerAttack의 표식 리셋과 별도 상태이므로 발사·취소까지 수행한 뒤 효과 종료를 확인한다.
