## 2. 우선순위

**소리가 필요한 기준은 "내가 방금 무엇을 했는지 모를 때"다.** 눈으로 확실한 것에는 소리가 없어도 된다. 그 기준으로 거르면 40분 게임에 **12개 + BGM 3.5트랙**이면 충분하다.

| 순위 | 항목 | 근거 |
|---:|---|---|
| **1** | **BGM 3트랙 + 처치 큐** | 1장의 두 연출이 이것에만 의존한다 |
| **2** | `SfxPlayer` + `SoundCatalogSO` + **`AudioMixer` 그룹** | 클립 0개로도 지금 만든다. 나중에 만들면 12곳을 뒤져야 하고, **믹서 그룹은 나중에 못 나눈다**(4.2) |
| **3** | **패링 성공 · 실패 2종** | **타이밍 게임은 눈이 아니라 귀로 배운다.** 그리고 심사자는 화면을 안 봐도 성공을 안다 |
| 4 | 나머지 10종 | 아래 |

## 3. BGM — "볼륨감"은 크기가 아니라 다이내믹 레인지다

**크게 만들면 웅장해지지 않는다. 작았다가 커져야 크다.** 계속 큰 것은 웅장한 것이 아니라 시끄러운 것이다.

### 3.1 트랙 구성

| 트랙 | 길이 | 스템 | 근거 |
|---|---:|---|---|
| **개활** | **26분** | **4층** | 전체의 65%로 가장 길고 가장 지겹다. 투자는 여기에만 |
| 보스 1P | 3.2분 | 단일 | 짧다. 소울라이크 톤은 오히려 단순해야 한다 |
| 보스 2P | 4.8분 | 단일 | 짧다. **티저 3막에 재사용**([티저 9장](TEASER_DESIGN.md)) |
| 처치 큐 | ~15초 | 단일 | 무음 3초 뒤에 오는 것. 절 종 |

### 3.2 🔥 결계가 조여드는 것을 귀로 듣는다

**개활 트랙만 스템으로 나누고, 레이어를 결계 단계에 붙인다.**

```
개활 BGM
├ 0분~     베이스 레이어
├ 1차 축소  + 타악
├ 2차 축소  + 현
└ 3차 축소  + 전부 + 저음
```

**결계는 지금 UI로만 알린다** — 바닥 링과 축소 경고. 그런데 3인 코옵에서 사람들은 화면을 보지 않는다. 뛰고 있다.

**"음악이 두꺼워졌다"는 화면을 안 봐도 느껴진다.** 그리고 이것이 [16.4 "결계는 사냥터가 아니라 몰이다"](../class-identity-and-boss-2026-09-03.md)를 **청각으로 전달하는 방법**이다.

**26분째에 웅장한 이유는 그 소리가 커서가 아니라 처음에 얇았기 때문이다.**

### 3.3 무음 3초는 재개하지 않는다

곡 중간에서 3초를 끊고 재개하면 **박자가 어긋난다.** 처음부터 다시 틀면 그것은 다른 곡이 시작된 것이다.

```
보스 2P 트랙  →  [무음 3초]  →  처치 큐 (종소리)
```

**무음이 2P 곡의 끝이다.** 재개할 필요가 없고, 오히려 낫다 — 소리가 한꺼번에 돌아올 때 **돌아온 것이 아까 그 음악이 아니라 새로운 것**이면 더 강하다.

## 4. 재생 계층

### 4.1 구조

**서버 작업은 없다.** [NETWORK_AUTHORITY](NETWORK_AUTHORITY.md)가 *"히트 이펙트·사운드는 동기화하지 않음. 각 클라이언트가 로컬 재생"*으로 이미 계약을 박아 놓았다.

```
SoundCatalogSO   ← GameDB에 물린다. 밸런스 SO와 같은 방식
SfxPlayer        ← 정적. PlayOneShot + 풀링 + 같은 키 dedupe
AudioMixer       ← 아래 4.2
```

**클립이 0개여도 지금 만든다.** 나중에 만들면 호출 지점 12곳을 다시 뒤져야 한다.

### 4.2 믹서 그룹 — 지금 나눠야 한다

```
Master
├ BGM              ← Duck Volume. SFX_Critical을 사이드체인으로 문다
└ SFX
   ├ Combat_Critical   패링 성공·실패 · 꼬리 파괴 · 페이즈 전환
   └ Combat_Normal     타격 · 피격 · 구르기 · 잡귀 사망 · 화살
```

> 🔒 **SFX 12개를 다 만든 뒤에는 무엇이 중요한지 나눌 수 없다.**
> 그룹은 재생 계층을 만들 때 함께 잡는다.

### 4.3 덕킹 — 볼륨감이 패링을 죽이지 않고 살린다

**오케스트라를 깔면 0.32초짜리 패링음이 묻힌다**는 것이 3장의 유일한 실질 위험이다.

**해결은 볼륨을 줄이는 것이 아니라 사이드체인이다.** Unity `AudioMixer`의 **Duck Volume** 이펙트로, `Combat_Critical`이 울리면 BGM이 0.2초 물러났다 돌아온다.

**그러면 볼륨감을 키울수록 패링이 더 극적으로 들린다.** 대비는 크기가 만든다 — **조용한 게임에서는 패링음도 조용하다.**

## 5. 조달

### 5.1 배분

| 대상 | 수단 | 근거 |
|---|---|---|
| **BGM 3.5트랙** | **Suno (유료)** | 5.2 |
| 절 종 · 징 · 장구 | 유료 라이브러리 또는 Suno | [9.8](../02-game-design.md)의 *"처치 = 종소리 하나"*는 **절 종**이어야 하고 CC0에 드물다 |
| 타격 · 피격 · 구르기 등 7종 | **CC0 (Freesound · Kenney)** | 어차피 가공한다 |
| **먹 번짐 1** | CC0 | 물에 잉크를 떨어뜨린 소리. 흔하다 |
| **티저 육성 1줄** | 팀원 녹음 + 리버브 · 피치 | [티저 6.2](TEASER_DESIGN.md) |
| SFX 보조 | **ElevenLabs — 인증 필요** | 5.4 |

### 5.2 ⚠️ Suno는 처음부터 유료로 시작한다

**무료 티어로 프로토타이핑하지 않는다.**

| 사실 | 결과 |
|---|---|
| **무료 시절 곡은 결제해도 소급 라이선스가 붙지 않는다** | 마음에 든 곡을 **버리고 다시 만들어야 한다** |
| AI는 같은 프롬프트로 같은 곡을 다시 못 만든다 | **그 곡은 영영 못 되찾는다** |
| [Steam 전환](../../.claude/docs/2026-09-02/steam-stage0-spike.md)이 이미 진행 중이다 (FizzySteamworks · PR 머지됨) | 상업적 사용 가능성이 실재한다 |

**Premier가 필요하다.** Pro와 Premier의 **상업적 권리 범위는 동일**하지만 **스템 분리는 Premier에만 있고**, 3.2의 개활 레이어링이 스템을 전제한다. **1개월 구독으로 3.5트랙과 스템을 뽑고 해지하는 것이 현실적이다.**

**2026년 변경 사항 두 가지를 알고 간다** — 소유권 문구가 "User Owned"에서 **"Granted Commercial Rights"**로 바뀌었고, Suno는 **저작권이 귀속된다는 보장을 하지 않는다**고 명시한다. 유료 티어에도 월 다운로드 상한이 생겼다.

### 5.3 루프는 자동으로 안 된다

Suno 출력은 시작과 끝이 뚜렷해서 그대로 넣으면 이어지지 않는다.

- 프롬프트: `no intro, no outro, seamless loop, no vocals, consistent energy, [BPM]`
- **DAW에서 4/4 마디 경계로 직접 자른다**
- **잘못 자른 이음매는 40분 내내 반복된다.** 자르고 나서 반드시 길게 돌려본다

**Suno는 곡을 만들지 큐(cue)를 만들지 않는다.** 인트로·후렴·아웃트로가 있는 3분 곡을 26분 구간에 그대로 넣으면 같은 후렴을 여덟 번 듣는다. 3.2의 스템 레이어링이 이것도 함께 완화한다.

### 5.4 ElevenLabs — 인증이 먼저다

**음악은 Suno가 낫지만 효과음은 ElevenLabs가 낫다.** 2.1의 타격·구르기·잡귀 사망 같은 것은 텍스트로 뽑는 편이 CC0를 뒤지는 것보다 빠르다.

**단 현재 이 프로젝트의 ElevenLabs 커넥터는 인증되지 않은 상태다.** claude.ai 커넥터 설정에서 인증을 마쳐야 사용할 수 있다.

### 5.5 🚨 `docs/licenses/`를 먼저 채운다

**소리를 받아오기 전에 채운다.** 지금 비어 있다.

- Suno가 **저작권 귀속을 보장하지 않는다**고 명시한 상황이므로 더더욱 기록이 필요하다
- 포트폴리오 심사에서 *"이 음악 어디서 났느냐"*는 실제로 나오는 질문이다
- CC0도 출처·라이선스·받은 날짜를 남긴다. **출처 불명 에셋은 그 자체가 감점이다**

## 6. 구현 순서

```
1. AudioMixer 그룹 4개 (Master / BGM / Combat_Critical / Combat_Normal)
2. SoundCatalogSO + SfxPlayer         ← 클립 0개로
3. BGM 재생 + 보스 2P 트랙 하나        ← 9.8 무음 3초가 여기서 살아난다
4. 패링 성공·실패 2종 + Duck Volume 배선
5. 나머지 SFX 10종
6. 개활 스템 4층 + 결계 단계 연동      ← 3.2
```

**1번부터 하는 이유** — 그룹은 나중에 못 나눈다(4.2).
**3번이 4번보다 먼저인 이유** — 덕킹은 눌릴 BGM이 있어야 검증된다.

## 7. 검증

| 수준 | 항목 |
|---|---|
| L1 | 컴파일 에러 0. `GameDB`에 `SoundCatalogSO`가 물린다 |
| L2 | 같은 키를 한 프레임에 여러 번 호출해도 **한 번만 재생된다** (dedupe) |
| L2 | **패링 성공 시 BGM이 눌렸다 돌아온다.** 오케스트라가 깔린 상태에서 패링음이 들린다 |
| L2 | 개활 트랙을 **10분 이상 돌려 이음매가 들리지 않는다** |
| **L3** | **3인 접속.** 세 클라이언트가 각자 로컬 재생하고, 같은 이벤트에 이중 재생이 없다 |
| **L3** | 결계 축소 3회에 레이어가 각각 추가되고, 세 사람이 같은 시점에 듣는다 |
| L2 | 보스 2P 트랙 → 무음 3초 → 처치 큐 전환이 끊기지 않는다 |
