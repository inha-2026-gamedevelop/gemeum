# 검·활 전투 개편 구현 기록

2026-09-22. 기준 기획: [플레이어 전투 개편안 v4](PLAYER_COMBAT_REWORK.md).

## 적용 범위

- 검: 같은 적의 같은 공격 실행에서 서로 다른 타격을 패링하면 반격 표식 최대 3개. 유지 2초, 공격 종료 후 최대 1.2초. HP 피해·회피·무기 변경·사망·씬 전환에서 폐기한다.
- 보스 1페이즈 연타: 1·2타 튕겨내기는 방어한 사람만 보호하며 공격을 중단하지 않는다. 마지막 타격은 기존 특수 카운터·그로기 규칙을 유지한다. 2페이즈 전이 규칙도 유지한다.
- 기본 검 R: 스태미나 16, 재사용 5초, 공격력 1.4배. 반격 R: 1/2/3표식에 1.2/2.6/4.5배, 기본 R 쿨다운과 독립. 표식은 요청 수락 때 예약하고 스태미나는 타격 시점에 지불한다. 빗나가도 지불하며 타격 전 취소는 표식만 잃는다.
- 패링 성공: 사용한 스태미나 환급. 기존 게이지 100 보상과 추가 무적을 제거했다. 일반 치명타는 유지한다.
- 활: R 접근·쐐기 설치, 일반 화살 두 번 또는 정밀 사격 한 번으로 파열. 신규 특성으로 비용·유지 시간·파열·관통·회피 후 연계를 연결했다. 화살은 발사 때의 특성을 사용하며 무기 변경 이후 남아 있는 화살은 특성 권한을 되살리지 않는다.
- 검·활 각각 뿌리 1개와 4개 노드로 구성한 세 갈래, 13개 노드·9포인트. 방울까지 총 39개. 노드 이름뿐 아니라 실제 전투 계산에 연결했다.
- 검 기본 베기와 반격의 선딜에 맞춘 R 모션을 별도로 연결했다. 공격 방향을 모델에 즉시 반영하며 검 락온은 요청 시점에 방향을 확정한다.
- 마지막 0.12초에 입력 하나를 예약한다. 우선순위는 회피, 패링/치유, R/Q, 평타 순. 일시정지·피격·런/씬/무기 변경에서 예약을 버린다.

## 데이터와 호환성

수치는 CombatConfigSO·TalentTreeSO·EquipmentSO에서 관리한다. 기존 장비 옵션 200은 신규 생성에서 제외하고 203 반격 유지 옵션으로 대체했다. 기존 숫자 ID는 재사용하지 않는다. 관통 상한은 ArrowConfigSO의 MaxPierceCount(기본 8)로 명시했다. 노드 2108의 추가 관통은 일반·정밀 화살 모두에 적용한다.

## 검증과 제한

- Unity EditMode 659개: 658 통과, 기존 NavMesh 런타임 검사 1개 제외.
- 검 표식 중복·공격 세대 교체·유예, 단계별 피해, 빗나감/취소 비용, 기본 쿨다운 독립, 보스 방어 대상 격리, 입력 우선순위 회귀 검사를 포함한다.
- 런처 수동 새로고침: WPF 실제 타이머 검사에서 비참가 시 통신 없음, 참가 시 파티 pulse만 발생, 목록 객체 유지, 수동 조회 시에만 목록 요청 증가를 확인했다.
- Development `win64-20260922-0020`: 같은 PC의 3프로세스에서 검 표식·기본 쿨다운 중 반격·피해 동기화, 활 일반 2회/정밀 1회 파열, 방울 설치·버프 회귀 검사를 통과했다. 반격 표식의 M2 입력은 검증용 공격 시퀀스를 공급하며 실제 보스 패링 입력 검증을 대체하지 않는다.
- 활 명중 시 호스트 중단을 재현해 쐐기 처리 인자를 작은 문맥 구조체로 변경했고, 동일 경로 재검증을 통과했다. 관련 EditMode 47개도 재통과했다. 2026-09-22 운영 게시 완료: 게임0.0.7(`win64-20260922-0020`), 런처1.2.10, AWS 허용 빌드0020.
- 재미·수치 밸런스, 실제 서로 다른 PC/인터넷 지연 환경, 새 모션에 대한 사용자 체감 평가는 별도다. 이번 구현은 전체 캐릭터 애니메이션 자산의 재제작을 의미하지 않는다.
