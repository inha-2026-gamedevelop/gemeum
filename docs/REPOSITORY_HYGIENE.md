# 저장소 포함·제외 기준

소스와 재현에 필요한 공유 설정은 Git에 남기고, 비밀값·개인 기록·재생성 가능한 실행 산출물은 제외한다. 실제 적용 규칙은 루트 및 하위 `.gitignore`다.

## Git에 남기는 것

- 게임·런처·백엔드 소스, 팀 소유 씬·프리팹·SO·모델·이미지와 해당 `.meta`.
- Packages의 manifest/lock, 백엔드 pyproject/uv.lock·Alembic 마이그레이션, 런처 프로젝트/솔루션, 티저 package/lock.
- 값이 비어 있거나 예시값만 있는 환경 설정 템플릿과 배포 스크립트.
- 팀 공유 `docs/`, Claude/Codex 스킬·에이전트 정의와 저장소 정책.
- 런처 공개키와 공개 API/패치 주소 등 클라이언트 배포에 필요한 공개 설정.

파일 크기나 확장자 하나만 보고 소스를 숨기지 않는다. `.json`, `.dll`, `.png`, `.meta` 전체 제외는 프로젝트 재현과 Unity 참조를 깨뜨릴 수 있다. 대용량 에셋은 기존 `.gitattributes`의 LFS 분류를 따른다.

## Git에서 제외하는 것

| 종류 | 예 |
|---|---|
| 비밀 환경 | 실제 .env 변형, 실제 service.env/discord.env, 로컬 자격증명 |
| 개인키 | SSH·배포 서명 개인키, 비밀번호가 필요한 인증서 묶음 |
| 실행 데이터 | 로컬 DB, DB 백업, 테스트 사용자·토큰 저장, 로컬 배포 상태 |
| 생성물 | Unity Library/Temp/Builds, Python 캐시·가상환경, .NET bin/obj, Node 의존성·출력 |
| 진단 | 실행 로그, 테스트 결과·커버리지, 임시 덤프·스크린샷 |
| 개인 AI 작업 | 개인 세션 기록·검토 초안·캡처·로컬 도구 설정 |
| 별도 반입 에셋 | 프로젝트 정책상 Git으로 배포하지 않는 구매 원본 |

개인 작업 파일의 저장 위치는 루트 지침을 따른다. 공용 스킬과 에이전트 정의는 개인 실행 기록과 구분해 유지한다. `.env.example`이나 `*.env.example`도 실제 비밀값을 넣으면 공유할 수 없다.

## 이미 추적된 파일

`.gitignore`는 이미 추적하는 파일에 소급 적용되지 않는다. 제외할 파일이 인덱스에 있다면 대상 파일을 확인한 뒤 **로컬 파일은 유지하고 추적만 해제**한다. 저장소 전체를 한꺼번에 untrack/add하지 않는다. 추적 해제는 다음 커밋에 삭제 변경으로 표시되며 커밋·푸시는 별도 요청 범위다.

추적 해제해도 이전 커밋의 내용은 사라지지 않는다. 실제 자격증명 노출이 발견되면 해당 자격증명을 폐기·교체하고 과거 기록 처리는 별도 판단한다.

## 변경 검증

1. 추적 파일과 미추적 파일을 각각 확인한다. 새 소스가 아직 커밋되지 않았다는 이유로 생성물로 분류하지 않는다.
2. 대표 비밀/캐시 경로가 Git 제외 대상인지, 환경 예제·공개키·소스·프로젝트 파일이 계속 포함되는지 확인한다.
3. 인덱스에 남은 무시 대상과 의도하지 않은 staged 변경을 확인한다.
4. 실제 비밀 내용을 출력하지 않는 방식으로 후보를 검사한다. 패턴 검사 통과는 모든 비밀이 없다는 보증이 아니다.
5. 문서 링크와 Unity `.meta` 쌍, 소스/설정 원본의 포함 상태를 확인한다.
