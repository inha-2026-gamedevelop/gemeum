이 다섯이 빠지면 게임이 아니다.

## 4. 게이트

각 주차의 "닫아야 하는 것"은 **관찰한 것만** 통과로 센다.

| 수준 | 의미 |
|---|---|
| L1 | 컴파일 에러 0, 신규 경고 없음 |
| L2 | 담당 `Dev_*` 씬에서 대상 동작 1회 이상 관찰 |
| **L3** | **3인 접속에서 확인** |

**네트워크가 걸린 것은 예외 없이 L3다.** 절차는 [멀티플레이 테스트](ai/04_MULTIPLAYER_TEST_PROTOCOL.md).
기록은 "3인으로 테스트했습니다"가 아니라 **무엇을 몇 회 확인했는지**를 남긴다.
EditMode 통과와 빌드 성공은 L3의 증거가 아니다.
