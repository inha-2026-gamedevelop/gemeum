W2 종료 시점의 정산이다. "관찰한 것만" 통과로 센다.

| `Lobby.unity` 바닥·스폰 | 통과 |
| 역할 3종 중복 없이 배정 · 무기 선호 | 통과(로컬). Steam 로비 선호 누락 수정분은 3PC 미검증 |
| 패링 3인 일치 20/20 | **기록 없음.** 개발 씬 결계 3인 검증 도구는 있음 |
| 결계 축소가 세 화면에서 같다 | HUD 결계 원·시간은 3인 결과로 갱신된 기록 있음. 피해·경고까지 20회 기록은 없음 |

W2 종료 조건 중 둘(패링 20/20 · 결계 20회)은 미통과다. 코드가 없어서가 아니라 3인 세션이 없어서다. **W3 첫 일정이 3PC 세션이다.**

코드로 끝난 것이 생각보다 많다. 장비 · 12칸 인벤토리 · 드랍 · 양도 · 상점 · 물약 · 재화 · 부활 차감 · 경험치 · 특성 39노드(무기별 13) · 정산 · 평가 등급 · 로컬 리더보드 · 관리 창 4탭 · 결과 화면 · 이탈 대기 UI · 보스 게이트 30초 · 꼬리 3덩이 · 25% 게이트 · 그로기 3직업 · 광폭화 · 원혼 셋 · 백귀야행 · 삼켜짐 · 몰이 · 정밀 사격 카운터 · 타격감 4/5. 상세는 [로드맵 1장](05-implementation-roadmap.md).

## 5. 게이트

각 주차의 "닫아야 하는 것"은 **관찰한 것만** 통과로 센다.

| 수준 | 의미 |
|---|---|
| L1 | 컴파일 에러 0, 신규 경고 없음, EditMode 전부 통과 |
| L2 | 담당 `Dev_*` 씬에서 대상 동작 1회 이상 관찰 |
| M2 | 단일 PC 다중 프로세스 접속. **봇 충원 포함 가능** |
| **L3 / S2** | **서로 다른 PC 3대 접속.** Steam 경로면 S2 |

**네트워크가 걸린 것은 예외 없이 L3다.** 절차는 [멀티플레이 테스트](ai/04_MULTIPLAYER_TEST_PROTOCOL.md).
**사람 1 + 봇 2 통과는 M2다. L3가 아니다.** 봇은 원격 클라이언트의 RTT·예측·표현 경로를 타지 않는다.
기록은 "3인으로 테스트했습니다"가 아니라 **무엇을 몇 회 확인했는지**를 남긴다.
EditMode 통과와 빌드 성공은 L3의 증거가 아니다.
